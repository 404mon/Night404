# Changelog

## [1.1.0] — Nightfall Update (unreleased)

### Added

- Nightfall heading gradients, semantic text gradients and subtle glow.
- Multiline heading styling and distinct gradients for formatted heading content.
- Folder, inactive note, tab and note title gradients.
- Optional Style Settings controls for code backgrounds, borders, typography, corner radius, line height, gradients and glow.
- Contribution guidelines.

### Changed

- Improved syntax highlighting in Reading View and CodeMirror.
- Preserved the original palette, with Dark Gray as the default code background and Deep Night as an alternative.
- Refactored Markdown formatting, selection, callouts and Canvas styling.
- Removed all `!important` declarations from the theme CSS.
- Updated the manifest compatibility target to Obsidian 1.13.4 (pending final compatibility tests).
- Updated installation and customization documentation.

### Fixed

- Removed unsupported manifest fields.
- Improved preservation of semantic colors and inline code backgrounds inside headings.

## [1.0.0]

- Original Night404 release, including the nighttime palette, custom typography, callouts and Canvas styling.
